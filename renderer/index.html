环境迁移与卸载

一键导出或恢复可迁移环境，并按所选范围清理本机数据

“连同启动器导出”生成解压即用的完整 ZIP：运行 DSH Manager.exe 后自动绑定随包环境，首次启动自动安装依赖。两种导出都排除 API Key、凭据、会话和日志；目标电脑需重新填写 API Key。

默认只清理管理器设置与缓存。便携版不注册系统安装项，数据清理后手动删除下载的 EXE 或整个解压目录即可。
